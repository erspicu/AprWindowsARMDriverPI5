## 關鍵 know-how
- WDDM render KMD：`DriverEntry` → 填 `DRIVER_INITIALIZATION_DATA`（38 個 `DxgkDdi*`）→ `DxgkInitialize`。link **`displib.lib`**（同 DOD；非 dxgkrnl.lib）。entry `GsDriverEntry`。
- DDI 是**函式 typedef**（`NTSTATUS DXGKDDI_XXX(...)`），參數用 WDK 巨集型別：
  - PnP（dispmprt.h）：`IN_CONST_PVOID`、`OUT_PPVOID`、`IN_PDXGK_START_INFO`、`IN_PDXGKRNL_INTERFACE`、`OUT_PULONG`、`INOUT_PDXGK_CHILD_STATUS`…
  - render/VidPn（d3dkmddi.h）：`IN_CONST_HANDLE`、`INOUT_PDXGKARG_*`、`IN_CONST_PDXGKARG_*`、VidPn 的 `..._CONST` 變體（如 `IN_CONST_PDXGKARG_COMMITVIDPN_CONST`）。
  - 定義端用**相同巨集型別**即與 typedef 配對；SAL-only 參數（如 QueryChildRelations 的 `_Inout_updates_bytes_`）可省 SAL 只留 C 型別。
- stub 回傳：render/VidPn → `STATUS_NOT_IMPLEMENTED`；lifecycle（Start/Stop/Destroy）→ `STATUS_SUCCESS`；`StartDevice` 設 `*NumberOfVideoPresentSources=0`、`*NumberOfChildren=0`（render-only，顯示走 DOD）；Interrupt→`FALSE`；Dpc→VOID；AddDevice 配 adapter context。

## 餘下（需實機 + UMD）
- V3D MMU、control list（CL）/ BCL/RCL 提交、bin/render job、fence/sync、效能計數。
- **user-mode D3D driver（UMD）**（Mesa v3d/Gallium → D3D/DXGI 對接），這是讓 3D 真正可用的另一大塊。
- 顯示輸出仍由 DOD（`rp1vc4dod.sys`）或 vc4 modeset 負責。
