# RP1 DesignWare I2C → SpbCx 驅動 know-how

> 日期：2026-06-21 04:30　｜　產出：`windows_driver/i2c/rp1i2c.sys`（ARM64, KMDF+SpbCx, 14.8 KB）

## 成果
- 專案 `windows_sources/i2c/rp1-dw-i2c/`：`dw_i2c_hw.{h,c}`（HAL）+ `common.h` + `driver.c`（SpbCx 控制器）+ `build.ps1`。
- 第一個 **SpbCx** 驅動；建立可複用 pattern（SPI `dw-apb-ssi`、BCM2712 I2C 可套用）。

## 移植來源
- `i2c-designware-core.h`（暫存器圖：CON/TAR/DATA_CMD/SS+FS_SCL_HCNT/LCNT/INTR/ENABLE/STATUS/COMP_TYPE=0x44570140）
- `i2c-designware-master.c::i2c_dw_configure_master`（CON = MASTER|SLAVE_DISABLE|RESTART_EN|speed）

## SpbCx 驅動骨架（已驗證）
- `EvtDeviceAdd`：**`SpbDeviceInitConfig(DeviceInit)` 要在 `WdfDeviceCreate` 之前**；之後 `SPB_CONTROLLER_CONFIG_INIT` 設 callback、`SpbDeviceInitialize(device, &cfg)`。
- `SPB_CONTROLLER_CONFIG` callback：`EvtSpbTargetConnect`/`Disconnect`、`EvtSpbIoRead`/`Write`/`Sequence`（Lock/Unlock 可 NULL）。
- 完成請求：`SpbRequestComplete(Request, Status)`。

## 踩雷（已解）
1. **`EVT_SPB_TARGET_DISCONNECT` 回傳 `VOID`**（`EVT_SPB_TARGET_CONNECT` 回 `NTSTATUS`）→ 用函式 typedef 前向宣告時，定義端型別要一致（C2371）。I/O callback（Read/Write/Sequence）也是 `VOID`。
2. **`SPBREQUEST` 與 `WDFREQUEST` 是不同 handle 型別**：呼叫 `WdfRequestRetrieveInput/OutputBuffer`、`WdfRequestSetInformation` 要 cast `(WDFREQUEST)Request`（否則 C4133）。
3. include：`wdf\kmdf\1.33` + **`km\spb\1.1`**（spbcx.h）+ `km\crt`/`km`/`shared`。
4. link：KMDF（`wdfdriverentry.lib`+`wdfldr.lib`，entry `FxDriverEntry`）+ **`spbcxstubs.lib`**（在 `Lib\...\km\arm64\spb\1.1\`）。

## HAL 重點
- `DwI2cHwProbe`：讀 COMP_TYPE 驗證 + COMP_PARAM_1 取 FIFO 深度。
- `DwI2cHwConfigureMaster`：disable→寫 CON→寫 SS/FS SCL HCNT/LCNT（**目前為 nominal 值；TODO 以 RP1 clock 用 `i2c_dw_scl_hcnt/lcnt` 計算**）→TX/RX 門檻→INTR_MASK=0（polled）。
- `DwI2cHwSetTarget`：disable→寫 TAR(7-bit)→enable。
- `DwI2cHwWrite/ReadPolled`：等 TFNF/RFNE，寫/讀 DATA_CMD（最後一筆帶 STOP），檢查 TX_ABRT。

## 待精修（多數需實機/clock driver）
- target 位址從 ACPI I2C serial-bus descriptor 解析（`SpbTargetGetConnectionParameters` → 解 `PNP_I2C_SERIAL_BUS_DESCRIPTOR`）
- SCL 時脈計算、中斷模式（接 #4 GpioClx demux 的 IRQ）、`EvtSpbIoSequence`（SPB_TRANSFER_LIST 組合傳輸）
- INF（含 WDF coinstaller）

## 連帶解鎖
- **SPI（`dw-apb-ssi`）**、**BCM2712 I2C（`i2c-brcmstb`）** 可直接套此 SpbCx pattern，換暫存器層即可。
