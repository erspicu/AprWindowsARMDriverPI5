# A7：BCM2712 DMA（DMA40 40-bit 引擎，bespoke KMDF）

> 「移植時抄錯硬體變體，整組暫存器圖都不對」的最佳教材——BCM2712 用的是 **40-bit DMA40** 引擎，
> 不是舊的 bcm2835 legacy DMA。

| | |
|---|---|
| **裝置** | BCM2712 DMA 控制器（DMA40，40-bit 位址） |
| **Linux 源碼** | `drivers/dma/bcm2835-dma.c`（`is_40bit_channel` 路徑） |
| **Windows 框架** | bespoke KMDF |
| **本專案** | `windows_sources/dma/bcm2712-dma/` ｜ 狀態 🔵（sim 19/19，含 DMA40 path） |

## 1. 陷阱：同一個源碼檔，兩套暫存器圖

`bcm2835-dma.c` 裡其實有**兩套**：
- legacy bcm2835（32-bit）：`CS=0x00 ADDR=0x04 RESET=BIT31`
- **BCM2711/2712 DMA40（40-bit）**：`CS=0x00 CB=0x04 DEBUG=0x0c TI=0x10 …`，控制位也不同

移植時若只看到 legacy 那套就抄，**在 BCM2712 上整個對不上**（channel 不啟動、reset 無效）。
要看 `is_40bit_channel`/`is_2712` 分支，抄 DMA40 那套。

## 2. DMA40 三個關鍵序列（從源碼 is_40bit 路徑抄）

```c
// Start：control-block 位址是「實體位址 >> 5」，CS 帶 ACTIVE|PROT|flags
void DmaHw40Start(void *Base, unsigned ch, unsigned CbAddr40, unsigned Dreq) {
    unsigned c = ch * CHAN_SIZE;
    WR32(Base, c + BCM2711_DMA40_CB, CbAddr40);   // = paddr >> 5
    WR32(Base, c + BCM2711_DMA40_CS,
         BCM2711_DMA40_ACTIVE | BCM2711_DMA40_PROT | BCM2711_DMA40_CS_FLAGS(Dreq));
}

// Reset：pause(清 ACTIVE) → 等 TRANSACTIONS 清 → CS=PROT → DEBUG|=DEBUG_RESET
void DmaHw40Reset(void *Base, unsigned ch) {
    unsigned c = ch * CHAN_SIZE;
    if (RD32(Base, c + BCM2711_DMA40_CB) == 0) return;            // idle = CB 為 0
    WR32(Base, c+DMA40_CS, RD32(Base, c+DMA40_CS) & ~DMA40_ACTIVE);
    /* 輪詢 TRANSACTIONS 清 */
    WR32(Base, c+DMA40_CS, BCM2711_DMA40_PROT);
    WR32(Base, c+DMA40_DEBUG, RD32(Base, c+DMA40_DEBUG) | BCM2711_DMA40_DEBUG_RESET);
}

// Ack：寫 INT 清中斷，但「保留 ACTIVE」(否則 cyclic 傳輸會被中斷)
void DmaHw40AckInt(void *Base, unsigned ch, unsigned Dreq) {
    WR32(Base, ch*CHAN_SIZE + DMA40_CS,
         DMA40_INT | DMA40_ACTIVE | DMA40_PROT | DMA40_CS_FLAGS(Dreq));
}
```

## 3. 三個 DMA40 特有點（容易抄錯）

| 點 | 說明 |
|----|------|
| **CB = paddr >> 5** | 40-bit 引擎的 control-block 位址要先右移 5（`to_40bit_cbaddr`） |
| **PROT 位** | start/ack 都要帶 `PROT(BIT8\|9)`，否則存取保護錯 |
| **reset 不在 CS** | DMA40 的 reset 是 `DEBUG\|=DEBUG_RESET`，不是 legacy 的 `CS=BIT31` |
| **ack 保留 ACTIVE** | legacy 習慣清 ACTIVE；DMA40 cyclic 要保留，否則傳輸中斷 |

## 4. 教學點

> 這章的價值在「**先確認硬體變體**」。同一份 Linux 驅動常支援多代晶片，分支藏在 `is_xxx` 旗標裡。
> 移植前要先用實機（`lspci`/DT compatible）確認「這塊板實際是哪個變體」（A 類：實際生效配置），
> 否則抄錯整組白做。最終 DMA 時序/cache coherency 仍需實機核對。
